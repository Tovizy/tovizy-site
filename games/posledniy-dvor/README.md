# Последний двор — веб-версия

Браузерная игра студии «Зашибатька». Отдельный проект Vercel `posledniy-dvor` с корнем в этой папке: https://posledniy-dvor.vercel.app

- `index.html` — русская версия, `game_en.html` — английская; язык выбирается по браузеру, на стартовом экране есть кнопка переключения.
- Версия без SDK и рекламы GamePush (сборка для площадок живёт отдельно).
- Обновляется заменой файлов в этой папке.
