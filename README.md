# Чердушки — файлы серий

Ветка для раздачи готовых серий мультсериала «Чердушки» (cherdushki.ru) при публикации в соцсетях.
Не связана с сайтом в ветке main; деплой Vercel для этой ветки выключен.

`publish_prep.sh` — сжатие серии под 29 МБ, обложка в JPG, коммит в эту ветку и печать ссылок для Metricool.

Опубликовано 26.10.2026: серия 1 «Первая ночь», серия 2 «Кто сидит на стуле?» (TikTok, YouTube Shorts).
